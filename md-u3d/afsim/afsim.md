# 1.AFSIM
既然有公司招聘 AFSIM（高级框架综合仿真，Advanced Framework for Simulation, Integration, and Modeling），说明你正接触到防务仿真领域的“硬核”技术。
AFSIM 最初由美国空军研究实验室（AFRL）开发，目前是全球军事仿真、运筹分析和作战效能评估的标准工具之一。在中国，这类需求通常集中在航空、航天、电科等大型军工集团的研究所。

以下是学习 AFSIM 的系统路径：
## 1. 理解核心定位
AFSIM 不仅仅是一个软件，它是一个基于 C++ 的仿真框架。它不是用来画 3D 模型的，而是用来模拟“导弹能不能打中”、“雷达能不能看见”、“预警机如何调度”等逻辑与效能问题。
## 2. 学习路径四部曲
### 第一步：掌握脚本语言脚本 (EL - Expert Language)
    AFSIM 的大部分场景构建不需要改动 C++ 底层，而是通过一种自研的脚本语言 EL 来编写。
    学习重点：了解如何定义实体（Platform）、传感器（Sensor）、武器（Weapon）以及它们之间的交互逻辑。
    类比：EL 脚本有点像简化的 C++ 和 JSON 的结合体，你需要学会如何描述一个“如果雷达发现目标，就发射导弹”的策略。
### 第二步：精通 C++ 底层开发（进阶核心）
    如果你应聘的是高级开发岗位，公司看重的是你扩展 AFSIM 的能力。
    学习重点：如何通过 C++ 编写新的算法插件（如定制的电子对抗模型、新的制导律）。
    技术栈：深度理解 C++ 类继承、插件机制以及如何在 AFSIM 框架下进行二次开发。
### 第三步：学习任务/交战级建模逻辑（高级核心）
    AFSIM 的精髓在于 LOD（建模粒度）。
    学习重点：熟悉它的空间模型（地心坐标系）、运动模型（6自由度/3自由度）和通信网络模型。
    应用场景：比如你提到的“车辆碰撞系统”是物理层的模拟，而 AFSIM 更多是“红蓝对抗”层面的逻辑模拟。
    第四步：熟悉可视化工具 (WIZARD)
    AFSIM 带有可视化显示界面。
    学习重点：如何配置场景视图，将仿真运行的数据导出为可分析的曲线或三维轨迹图。
## 3. 如何获取学习资源？
    由于 AFSIM 具有强烈的行业特殊性（军工/防务），资源不像 Web 开发那样到处都是：
    官方文档：如果你能进入相关研究所工作，这是最全的资源。
    GitHub/开源社区：搜索 AFSIM 相关项目。虽然核心内核不开源，但有很多公开的扩展包和论文说明。
    学术论文：在知网（CNKI）或 IEEE 搜索“基于 AFSIM 的作战效能评估”，能帮你快速理解这个工具是怎么用的。
    视频教程：YouTube 上有很多 AFSIM 相关的教学视频，如 AFRL 官方的“AFSIM 基础教程”。
## 4. 招聘方的核心考核点
建模能力：你能不能把一个复杂的战术逻辑抽象成模型？
数学基础：对坐标转换（ECEF/WGS84）、概率论（评估命中率）是否熟悉？
仿真框架经验：如果你以前用过 STK、MATLAB/Simulink 或 OMNeT++，会有很大加分。
