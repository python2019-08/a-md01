# 0.如何安装MicroK8s

MicroK8s 是 Canonical 开发的轻量级 Kubernetes 发行版，适合本地开发、测试和资源受限环境。以下是在不同操作系统上安装 MicroK8s 的详细步骤：


### **一、Ubuntu/Debian 系统**
**推荐方式：使用 Snap 包管理器**  
Ubuntu 系统默认预装 Snap，其他系统需先安装 Snapd：
```bash
# 安装 Snapd（非 Ubuntu 系统需要）
sudo apt update
sudo apt install snapd

# 安装 MicroK8s（稳定版）
sudo snap install microk8s --classic

# 查看安装状态
microk8s status --wait-ready
```

**替代方案（如果 Snap 不可用）​​**
替代方案 1：使用官方脚本安装​
```sh
# MicroK8s 也支持通过脚本安装（非 Snap 方式）：
curl -s https://microk8s.io/install.sh | sudo bash
```

### **二、macOS 系统**
**方式 1：使用 Homebrew（推荐）**
```bash
# 安装 Homebrew（如果未安装）
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

# 安装 MicroK8s
brew install ubuntu/microk8s/microk8s

# 启动 MicroK8s
microk8s start
```

**方式 2：使用 Multipass（虚拟机方式）**
```bash
# 安装 Multipass
brew install multipass

# 创建 MicroK8s 实例
multipass launch --name microk8s-vm --mem 4G --disk 20G
multipass exec microk8s-vm -- sudo snap install microk8s --classic

# 进入虚拟机使用 MicroK8s
multipass shell microk8s-vm
```


### **三、Windows 系统**
**方式 1：使用 WSL 2（推荐）**
1. **启用 WSL 2**：
   ```powershell
   wsl --install
   # 若需指定 Ubuntu 版本：
   wsl --install -d Ubuntu
   ```

2. **在 WSL 中安装 MicroK8s**：
   ```bash
   # 启动 WSL 终端
   sudo snap install microk8s --classic
   ```

**方式 2：使用 Hyper-V（官方推荐）**
1. **启用 Hyper-V**：
   - 控制面板 → 程序和功能 → 启用或关闭 Windows 功能 → 勾选 Hyper-V

2. **安装 Multipass**：
   - 从官网下载并安装：https://multipass.run/

3. **创建 MicroK8s 实例**：
   ```powershell
   multipass launch --name microk8s-vm --mem 4G --disk 20G
   multipass exec microk8s-vm -- sudo snap install microk8s --classic
   ```


### **四、验证安装**
安装完成后，验证 MicroK8s 是否正常运行：
```bash
# 检查状态（等待所有服务启动）
microk8s status --wait-ready

# 查看节点信息
microk8s kubectl get nodes

# 查看服务列表
microk8s kubectl get services
```


### **五、配置 MicroK8s**
#### **1. 启用常用插件**
```bash
# 启用 DNS、存储、Ingress 等插件
microk8s enable dns storage ingress helm3 registry

# 查看已启用的插件
microk8s status
```

#### **2. 将 MicroK8s 的 kubectl 设为默认**
```bash
# 创建 kubectl 别名
alias kubectl='microk8s kubectl'

# 或添加到环境变量（永久生效）
echo 'alias kubectl="microk8s kubectl"' >> ~/.bashrc
source ~/.bashrc
```


### **六、卸载 MicroK8s**
若需卸载，执行以下命令：
```bash
# 停止并卸载 MicroK8s
sudo snap remove microk8s

# 清理残留数据（可选）
sudo rm -rf ~/.kube/config
```


### **七、常见问题**
#### **1. 权限问题**
若执行命令时提示权限不足，可将当前用户添加到 `microk8s` 组：
```bash
sudo usermod -a -G microk8s $USER
newgrp microk8s  # 刷新组权限
```

#### **2. macOS 网络问题**
若无法访问集群服务，尝试重启 MicroK8s：
```bash
microk8s stop
microk8s start
```


### **八、验证安装成功**
安装完成后，可部署一个简单的 Nginx 服务测试：
```bash
# 部署 Nginx
microk8s kubectl create deployment nginx --image=nginx
microk8s kubectl expose deployment nginx --port=80 --type=NodePort

# 访问 Nginx
NODE_PORT=$(microk8s kubectl get svc nginx -o jsonpath='{.spec.ports[0].nodePort}')
echo "访问地址: http://localhost:${NODE_PORT}"
```


通过以上步骤，你可以在不同操作系统上成功安装并配置 MicroK8s。它提供了完整的 Kubernetes 功能，同时资源占用极小，非常适合开发和测试场景。

# 1.如何用MicroK8s做jenkins golang的 cicd

### MicroK8s环境下搭建Jenkins+Golang CI/CD流水线

MicroK8s是轻量级Kubernetes发行版，非常适合本地开发和测试环境。下面介绍如何在MicroK8s上部署Jenkins并配置Golang项目的CI/CD流水线。


### **步骤1：启用MicroK8s相关插件**

首先确保MicroK8s已安装并启用以下插件：

```bash
microk8s enable dns storage ingress helm3 registry
```

- `dns`: 集群DNS服务
- `storage`: 持久化存储支持
- `ingress`: 流量入口控制器
- `helm3`: Helm包管理工具
- `registry`: 本地镜像仓库


### **步骤2：使用Helm部署Jenkins**

添加Jenkins Helm仓库并部署：

```bash
# 添加Jenkins仓库
helm repo add jenkins https://charts.jenkins.io
helm repo update

# 创建命名空间
kubectl create namespace jenkins

# 创建值文件 jenkins-values.yaml
cat > jenkins-values.yaml <<EOF
controller:
  serviceType: NodePort
  nodePort: 30000
  adminPassword: "admin123"
  installPlugins:
    - kubernetes:latest
    - git:latest
    - pipeline:latest
    - golang:latest
persistence:
  enabled: true
  size: 8Gi
EOF

# 部署Jenkins
helm install jenkins jenkins/jenkins -n jenkins -f jenkins-values.yaml
```


### **步骤3：访问Jenkins并完成初始化**

获取Jenkins初始密码并访问Web界面：

```bash
# 获取初始密码
kubectl exec --namespace jenkins -it svc/jenkins -- /bin/cat /run/secrets/chart-admin-password && echo

# 访问Jenkins (NodePort方式)
http://<你的主机IP>:30000
```

使用初始密码登录后，安装推荐插件并创建管理员账户。


### **步骤4：配置Jenkins与Kubernetes集成**

1. 安装 **Kubernetes插件** 和 **Golang插件**
2. 配置Kubernetes云：
   - 管理Jenkins → 系统配置 → 云 → 添加Kubernetes
   - API Server地址: `https://kubernetes.default.svc.cluster.local`
   - 凭证选择自动生成的Kubernetes服务账户
   - 测试连接并保存


### **步骤5：配置Golang环境**

1. 管理Jenkins → 全局工具配置 → Golang
2. 添加Golang安装：
   - 名称: `go1.20`
   - 安装方式: 自动安装 → 选择版本


### **步骤6：创建Golang项目CI/CD流水线**

创建Jenkinsfile并添加到Golang项目仓库：

```groovy
pipeline {
    agent {
        kubernetes {
            label 'jenkins-go-agent'
            containerTemplate {
                name 'go'
                image 'golang:1.20'
                command 'sleep'
                args '99d'
            }
        }
    }
    
    environment {
        GOPATH = "${WORKSPACE}/go"
        PATH = "${PATH}:${WORKSPACE}/go/bin"
    }
    
    stages {
        stage('Checkout') {
            steps {
                checkout scm
            }
        }
        
        stage('Build') {
            steps {
                sh 'go build -v ./...'
            }
        }
        
        stage('Test') {
            steps {
                sh 'go test -v -cover ./...'
            }
        }
        
        stage('Build Docker Image') {
            steps {
                script {
                    def appImage = docker.build("localhost:32000/golang-app:${env.BUILD_NUMBER}", ".")
                    docker.withRegistry('http://localhost:32000', '') {
                        appImage.push()
                    }
                }
            }
        }
        
        stage('Deploy to K8s') {
            steps {
                sh """
                kubectl apply -f k8s/deployment.yaml
                kubectl set image deployment/golang-app golang-app=localhost:32000/golang-app:${env.BUILD_NUMBER} -n default
                """
            }
        }
    }
}
```


### **步骤7：配置Kubernetes部署文件**

在项目根目录创建`k8s/deployment.yaml`：

```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: golang-app
spec:
  replicas: 1
  selector:
    matchLabels:
      app: golang-app
  template:
    metadata:
      labels:
        app: golang-app
    spec:
      containers:
      - name: golang-app
        image: localhost:32000/golang-app:latest  # 会被Jenkins动态更新
        ports:
        - containerPort: 8080
```


### **步骤8：创建Jenkins Pipeline项目**

1. 新建Item → Pipeline
2. 配置源码管理（Git仓库URL）
3. 指定Jenkinsfile路径
4. 保存并构建


### **关键配置说明**

1. **本地镜像仓库**：
   - MicroK8s的registry插件默认监听32000端口
   - 需要在Jenkins节点上配置insecure-registry

2. **Pod安全上下文**：
   如果遇到权限问题，可能需要在Jenkinsfile中添加安全上下文配置：

```groovy
agent {
    kubernetes {
        label 'jenkins-go-agent'
        containerTemplate {
            name 'go'
            image 'golang:1.20'
            command 'sleep'
            args '99d'
            privileged true  // 可能需要特权模式
        }
        podSecurityContext {
            fsGroup 0  // 可能需要root权限
        }
    }
}
```


### **验证CI/CD流程**

1. 提交代码到Git仓库触发自动构建
2. 查看Jenkins控制台输出
3. 验证Docker镜像是否推送到本地registry
4. 检查Kubernetes中部署的应用是否正常运行：

```bash
kubectl get pods
kubectl logs <pod名称>
kubectl port-forward svc/golang-app 8080:8080
```


通过以上步骤，你就可以在MicroK8s环境下搭建完整的Jenkins+Golang CI/CD流水线了。根据实际需求，你还可以添加代码质量检查、自动化测试、部署到不同环境等更复杂的流程。
