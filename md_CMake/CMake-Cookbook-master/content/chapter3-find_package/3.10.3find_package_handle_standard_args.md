find_package_handle_standard_args

在 CMake 中，`find_package_handle_standard_args` 是一个用于**标准化处理 `find_package` 结果**的宏，通常用于自定义的 `Find<PackageName>.cmake` 脚本中。它的核心作用是：

1. **检查必需的组件或变量是否被找到**。
2. **统一设置 `<PackageName>_FOUND` 变量**。
3. **提供一致的错误或状态消息**（如 `Could NOT find <PackageName>`）。

---

## **1. 基本语法**
```cmake
find_package_handle_standard_args(
    <PackageName>
    [REQUIRED_VARS <var1> <var2> ...]  # 必须存在的变量
    [VERSION_VAR <version_var>]         # 版本变量（如 <PackageName>_VERSION）
    [HANDLE_COMPONENTS]                 # 启用组件支持
    [CONFIG_MODE]                       # 标记为 Config 模式（与 Find 模式区分）
    [FAIL_MESSAGE "Custom error message"]
)
```

---

## **2. 关键参数解析**
| **参数**             | **作用**                                                                 |
|-----------------------|--------------------------------------------------------------------------|
| `REQUIRED_VARS`       | 指定必须存在的变量（如 `SomeLib_INCLUDE_DIR` 和 `SomeLib_LIBRARIES`）。 |
| `VERSION_VAR`         | 指定版本变量（如 `SomeLib_VERSION`），用于版本检查。                     |
| `HANDLE_COMPONENTS`   | 启用对 `COMPONENTS` 的支持，自动检查请求的组件是否全部找到。             |
| `CONFIG_MODE`         | 声明当前是 `Config` 模式（与 `Find` 模式区分）。                        |
| `FAIL_MESSAGE`        | 自定义未找到包时的错误信息。                                             |

---

## **3. 典型用法示例**
### **场景 1：基础用法（无组件）**
假设你编写了一个 `FindSomeLib.cmake`，并找到了头文件和库：
```cmake
# FindSomeLib.cmake
find_path(SomeLib_INCLUDE_DIR some_lib.h)
find_library(SomeLib_LIBRARY some_lib)

# 标准化处理结果
include(FindPackageHandleStandardArgs)
find_package_handle_standard_args(
    SomeLib
    REQUIRED_VARS SomeLib_INCLUDE_DIR SomeLib_LIBRARY
    VERSION_VAR SomeLib_VERSION
)
```
- 如果 `SomeLib_INCLUDE_DIR` 和 `SomeLib_LIBRARY` 均被找到，则 `SomeLib_FOUND` 被设为 `TRUE`。
- 如果任一变量未找到，则输出错误并设置 `SomeLib_FOUND=FALSE`。

---

### **场景 2：支持组件（COMPONENTS）**
如果库支持组件（如 `SomeLib` 包含 `core` 和 `extra` 模块）：
```cmake
# FindSomeLib.cmake
find_package_handle_standard_args(
    SomeLib
    REQUIRED_VARS SomeLib_INCLUDE_DIR SomeLib_LIBRARY
    HANDLE_COMPONENTS  # 启用组件检查
)

# 检查请求的组件
if(SomeLib_FIND_COMPONENTS)
    foreach(component ${SomeLib_FIND_COMPONENTS})
        if(NOT SomeLib_${component}_FOUND)
            set(SomeLib_FOUND FALSE)
        endif()
    endforeach()
endif()
```

---

### **场景 3：版本检查**
如果库提供了版本信息：
```cmake
# 假设通过某些方式获取了版本（如解析头文件）
set(SomeLib_VERSION 1.2.3)

find_package_handle_standard_args(
    SomeLib
    REQUIRED_VARS SomeLib_INCLUDE_DIR SomeLib_LIBRARY
    VERSION_VAR SomeLib_VERSION  # 指定版本变量
)
```
- 如果调用 `find_package(SomeLib 2.0.0)` 且当前版本是 `1.2.3`，则会因版本不匹配而失败。

---

## **4. 工作原理**
1. **检查必需变量**：  
   如果 `REQUIRED_VARS` 中的任意变量未定义或为空，则判定包未找到。
2. **版本验证**（如果提供 `VERSION_VAR`）：  
   比较请求的版本（如 `find_package(SomeLib 2.0.0)`）和实际版本（`SomeLib_VERSION`）。
3. **组件处理**（如果启用 `HANDLE_COMPONENTS`）：  
   检查 `SomeLib_FIND_COMPONENTS` 中列出的组件是否全部找到。
4. **统一输出**：  
   根据结果设置 `<PackageName>_FOUND`，并打印成功/失败消息。

---

## **5. 常见问题**
### **Q1：为什么 `SomeLib_FOUND` 仍然是 FALSE？**
- **可能原因**：
  - `REQUIRED_VARS` 中的变量未正确设置（如 `SomeLib_INCLUDE_DIR` 为空）。
  - 版本不匹配（如请求 `2.0.0` 但找到 `1.0.0`）。
  - 组件未找到（启用 `HANDLE_COMPONENTS` 时）。

### **Q2：如何自定义错误消息？**
```cmake
find_package_handle_standard_args(
    SomeLib
    REQUIRED_VARS SomeLib_INCLUDE_DIR
    FAIL_MESSAGE "SomeLib not found. Please install it from https://example.com"
)
```

### **Q3：`CONFIG_MODE` 有什么用？**
- **区别**：  
  - `CONFIG_MODE` 表示当前是 `Config` 模式（优先查找 `<PackageName>Config.cmake`）。  
  - 默认是 `Find` 模式（查找 `Find<PackageName>.cmake`）。  
- **何时用**：  
  如果你在编写 `Find<PackageName>.cmake` 但想模拟 `Config` 模式的行为。

## **6. 完整示例**
### **自定义的 `FindSomeLib.cmake`**
```cmake
# 查找头文件和库
find_path(SomeLib_INCLUDE_DIR some_lib.h PATHS /opt/somelib/include)
find_library(SomeLib_LIBRARY some_lib PATHS /opt/somelib/lib)

# 获取版本（假设通过解析头文件）
if(SomeLib_INCLUDE_DIR)
    file(READ "${SomeLib_INCLUDE_DIR}/some_lib_version.h" VERSION_FILE)
    string(REGEX MATCH "SOME_LIB_VERSION_MAJOR ([0-9]+)" _ ${VERSION_FILE})
    set(SomeLib_VERSION_MAJOR ${CMAKE_MATCH_1})
    set(SomeLib_VERSION "${SomeLib_VERSION_MAJOR}.0.0")
endif()

# 标准化处理
include(FindPackageHandleStandardArgs)
find_package_handle_standard_args(
    SomeLib
    REQUIRED_VARS SomeLib_INCLUDE_DIR SomeLib_LIBRARY
    VERSION_VAR SomeLib_VERSION
    HANDLE_COMPONENTS
)

# 导出变量
if(SomeLib_FOUND)
    set(SomeLib_INCLUDE_DIRS ${SomeLib_INCLUDE_DIR})
    set(SomeLib_LIBRARIES ${SomeLib_LIBRARY})
endif()
```

## **总结**
- **核心作用**：标准化 `find_package` 的结果处理（设置 `_FOUND`、版本检查、组件支持）。
- **何时用**：在自定义的 `Find<PackageName>.cmake` 中调用。
- **关键参数**：
  - `REQUIRED_VARS`：必须存在的变量。
  - `VERSION_VAR`：版本检查。
  - `HANDLE_COMPONENTS`：支持组件。
- **最佳实践**：始终在 `Find` 脚本中使用它，确保与其他 CMake 模块行为一致。
