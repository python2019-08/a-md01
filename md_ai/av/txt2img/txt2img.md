# 0.显存需求小于 8G 的文生图模型，那效果最好的是哪个？

显存需求小于8G的文生图模型中，很难绝对地说哪个效果最好，不同模型在生成质量、速度、风格适应性等方面各有优势。以下是一些效果较好的模型介绍：
- **LCM-LoRA**：生成速度极快，通过减少扩散模型的迭代步骤，仅需1-4步即可达到传统模型30步的效果，将生成速度提升5-10倍。同时，它全面兼容Stable Diffusion生态，支持LoRA、ControlNet等插件。虽然相比原生Stable Diffusion，生成质量略有下降，但可通过调整LoRA权重弥补，适合对速度要求高的实时图像编辑等场景。
- **Fooocus**：4GB显存即可运行，集合了Midjourney“免配置”和Stable Diffusion“开源且本地免费使用”的优势。只要提示词准确，在默认设置下就能生成高质量的图片，且集成了大量预置样式，可快速生成对应风格的图片。  
       git clone https://github.com/lllyasviel/Fooocus.git
- **Meissonic**：仅1B参数可实现高质量图像生成，能在普通电脑上运行，无需额外优化。该模型通过引入改进的Transformer架构等技术，在高分辨率图像生成方面与当前最先进的扩散模型相媲美，显存需求较低，适合消费级GPU。
- **混元DiT**：腾讯开源的小显存版本，最低6G显存即可运行。基于DiT架构，生成图片质感更佳，且已适配到Diffusers库，开发者调用较为方便，还可接入Kohya，低门槛训练专属LoRA模型。
- **Wan2.1**：阿里巴巴开源的视频生成大模型，有14B和1.3B等版本，8GB显存的电脑即可运行。支持文生视频、图生视频等功能，可根据提示词生成如“雪地狂奔狐狸”等场景的视频，通过首尾帧过渡能生成较为丝滑的视频。
