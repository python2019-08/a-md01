# 2. k380 如何使用

以下是 **罗技 K380 蓝牙键盘** 的详细使用指南：

## 一、**首次连接设置**

### **蓝牙配对步骤**
1. **打开键盘**：拨动键盘背面开关至 ON 位置
2. **进入配对模式**：长按特定通道键（1/2/3）3秒，直到指示灯闪烁
3. **设备端搜索**：
   - **Windows**：设置 → 蓝牙 → 添加设备
   - **Mac**：系统偏好 → 蓝牙
   - **手机/平板**：设置 → 蓝牙
4. **选择设备**：在设备列表中选择 "K380"
5. **完成连接**：指示灯停止闪烁表示配对成功

## 二、**多设备切换**
K380 可同时连接 **3台设备**：
- **F1**：切换到设备1（蓝色指示灯）
- **F2**：切换到设备2（红色指示灯）  
- **F3**：切换到设备3（绿色指示灯）

## 三、**特殊功能键**
| 组合键 | 功能 | 说明 |
|--------|------|------|
| Fn + F1 | 返回主页 | 手机/平板适用 |
| Fn + F2 | 返回桌面 | Windows/Mac |
| Fn + F3 | 任务视图 | 多任务切换 |
| Fn + F4 | 截屏 | 系统截图 |
| Fn + F7/F8/F9 | 媒体控制 | 播放/暂停/静音 |
| Fn + F11/F12 | 音量调节 | 增减音量 |

## 四、**常见问题解决**

### **连接问题**
```bash
# 重置连接
1. 关闭键盘开关
2. 设备端删除已配对的 K380
3. 重新执行配对流程
```

### **电池更换**
- 使用 **2节AAA电池**
- 续航：约2年（正常使用）
- 低电量时指示灯会闪烁提示

## 五、**使用技巧**
1. **同时连接多个系统**：比如 PC + 手机 + 平板，一键切换
2. **兼容性**：支持 Windows、macOS、iOS、Android、Chrome OS
3. **便携性**：尺寸紧凑，适合外出携带

# 3.我的公司 只有一台电脑A能科网，我的ubuntu电脑和电脑A都是在一个tplink的局域网下。 我的ubuntu电脑上如何才能 通过电脑A 科网

要在你的Ubuntu电脑上通过电脑A（Windows系统）科网，最可靠的方法是在**电脑A上设置一个代理服务器**（例如 Shadowsocks, V2Ray 等代理软件自带的本地代理功能），然后**在Ubuntu电脑上配置网络代理设置**，将所有流量指向电脑A的局域网IP地址和代理端口。


以下是分步指南：
## 第一部分：在电脑A（Windows）上操作
确保你的电脑A已经安装了科网的客户端，并且可以正常连接并访问国际互联网。
### 1. 检查代理设置：
  大多数科网软件都会在本地开启一个代理服务。通常，这个服务的地址是 127.0.0.1（本地回环地址），端口号常见的是 1080、7890 或其他自定义端口。记下这个端口号。
### 2.允许局域网连接：
  在你的科网软件设置中，找到允许来自局域网 (LAN) 的连接的选项（通常是一个复选框）。勾选此选项。
  这个设置使得局域网内的其他设备（你的Ubuntu电脑）能够访问电脑A上的代理服务。
### 3.获取电脑A的局域网IP地址：
  在电脑A上，打开命令提示符 (Command Prompt) 或 PowerShell。
  输入命令 ipconfig 并按回车。
  找到你的活动网络连接（例如 "以太网" 或 "Wi-Fi"），记下其 IPv4 地址（通常是 192.168.x.x 格式）。
### 4.配置防火墙（重要）：
  确保 Windows 防火墙允许其他设备连接到你科网软件使用的端口。
  你可以添加入站规则，允许特定端口（例如上面记下的端口号）的连接。

## 第二部分：在Ubuntu电脑上操作
  确保你的Ubuntu电脑和电脑A在同一个局域网下（连接到同一个 TPLink 路由器）。
### 1.打开网络设置：
  进入 Ubuntu 的 设置 (Settings) -> 网络 (Network)。
  在左侧菜单中选择 网络代理 (Network Proxy) 或类似的选项。

### 2.手动配置代理：
  (2.1)将 方法 (Method) 或 配置 (Configuration) 设置更改为手动 (Manual)。
  (2.2)根据你的科网软件提供的代理类型（通常是 HTTP、HTTPS 或 SOCKS），填写相应的服务器地址和端口:
  HTTP 代理: 在 HTTP 代理 字段输入电脑A的 IPv4 地址 和代理端口号。
  HTTPS 代理: 在 HTTPS 代理 字段输入电脑A的 IPv4 地址 和代理端口号。
  SOCKS 主机: 如果你的代理软件提供 SOCKS 代理（通常端口是 1080），可以在 SOCKS 主机 字段输入电脑A的 IPv4 地址 和端口号。

### 3.应用设置：
点击应用到全系统 (Apply system-wide) 或保存按钮。
对于终端程序，你可能需要重新打开一个新的终端窗口，使代理设置生效。

完成以上步骤后，你的Ubuntu电脑上的网络请求就会通过电脑A上的代理服务器进行转发，从而实现科网。
